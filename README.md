# First Project — Python и AI-agent workflow

Учебный Python-проект, который постепенно развивается от простых скриптов к структурированной основе для изучения workflow с AI-агентами.

Проект используется для практики:

- организации Python-проектов и разделения кода на модули;
- работы с Git и историей изменений;
- использования виртуальных окружений и зависимостей;
- взаимодействия с AI-агентами при анализе и развитии проекта.

Сейчас основная программа импортирует модуль калькулятора из пакета `app`, складывает два числа и выводит результат.

## Требования

- Python 3.10 или новее;
- Git — для клонирования репозитория и работы с историей изменений.

Проверить установленную версию Python в Windows можно командой:

```powershell
py --version
```

## Структура проекта

```text
first-project/
├── app/
│   ├── __init__.py       # Обозначает каталог как Python-пакет
│   └── calculator.py     # Функции сложения и умножения
├── tests/
│   ├── __init__.py       # Пакет с учебными проверками
│   └── test_calc.py      # Проверка функции сложения
├── .gitignore            # Исключения для Git
├── hello.py              # Ранний учебный пример
├── main.py               # Основная точка входа
├── README.md             # Документация проекта
└── requirements.txt      # Зафиксированные зависимости
```

Каталог `.venv/` используется как локальное виртуальное окружение. Он исключён через `.gitignore` и не хранится в Git.

## Установка и запуск

### 1. Клонирование репозитория

```powershell
git clone <URL-репозитория>
cd first-project
```

### 2. Создание виртуального окружения

```powershell
py -m venv .venv
```

### 3. Активация в Windows PowerShell

```powershell
.\.venv\Scripts\Activate.ps1
```

После активации в начале строки PowerShell обычно появляется отметка `(.venv)`.

Если PowerShell блокирует выполнение скрипта активации, можно разрешить его только для текущего процесса:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

Настройка с областью `Process` действует только до закрытия текущего окна PowerShell.

### 4. Установка зависимостей

```powershell
python -m pip install -r requirements.txt
```

### 5. Запуск программы

```powershell
python main.py
```

Ожидаемый результат:

```text
8
```

## Пример использования

Точка входа импортирует пакет `app` и вызывает функцию сложения:

```python
from app import calculator

result = calculator.add(5, 3)
print(result)
```

Учебную проверку калькулятора можно запустить из корня проекта как модуль:

```powershell
python -m tests.test_calc
```

Ожидаемый результат:

```text
30
```
