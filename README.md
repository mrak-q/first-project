# Первый проект с ИИ-агентами

Небольшой учебный Python-проект, созданный для знакомства с разработкой MVP с помощью ИИ-агентов.

Сейчас приложение выводит в консоль приветственное сообщение:

```text
Я учусь создавать MVP с помощью ИИ-агентов!
```

## Требования

- Python 3.10 или новее

Проверить установленную версию Python можно командой:

```bash
python --version
```

На некоторых системах вместо `python` используется команда `python3`.

## Запуск

1. Клонируйте репозиторий и перейдите в каталог проекта:

   ```bash
   git clone <URL-репозитория>
   cd first-project
   ```

2. Запустите программу:

   **Windows**

   ```powershell
   python hello.py
   ```

   **macOS и Linux**

   ```bash
   python3 hello.py
   ```

После запуска в терминале появится:

```text
Я учусь создавать MVP с помощью ИИ-агентов!
```
